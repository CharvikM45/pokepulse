# Pokémon character artwork

Official character artwork retrieved from the [PokéAPI sprites repository](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork).
Pokémon and character artwork belong to their respective owners, including Nintendo, Creatures, and GAME FREAK. These illustrations are decorative character art; they are not product photographs and do not establish a card's inclusion in any expansion.
