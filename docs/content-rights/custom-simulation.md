# PokéPulse custom simulation configuration

Reviewed 2026-11-17 in response to the user's request to make Pack Lab functional.

This is an original, free virtual-card game. The configured Base Set, Pokémon 151 and Evolving Skies scenarios use ten independent uniform draws, with replacement, from one artwork-backed catalog variant per documented card. These are invented game rules, explicitly labeled as custom/fictional, and are not official booster contents or real-world pull-rate estimates.

The user authorized this app's card-image display and free simulation. Catalog metadata is attributed to TCGdex; card artwork is linked directly using its documented asset service and availability inventory. Pokémon and artwork copyrights remain with their respective owners. This record is project configuration authorization, not a claim of ownership, an external license agreement, endorsement, or official odds.

Only server-committed outcomes are presented. Retry/recovery reuses the immutable opening. Physical collections and valuations remain separate. No purchases, paid currency, transfers, cash value, redemptions or prizes exist. Configuration retains host, provider and per-variant gates, server rate limits and private account isolation.
